Every learning concept must be automatically logged into structured course notes (NOTES.md in each lesson directory). Notes should read like EdTech study material — well-organized, brief but complete, self-contained.

**Why:** The user wants a durable artifact from each session — not just conversation, but reusable course material someone could learn from by reading the notes and running the examples alone.

**How to apply:** After teaching any concept or writing any code example, immediately create/update the lesson's NOTES.md following the template in CLAUDE.md. Also update `notes/INDEX.md`. Don't wait until the end of a session — log as you go. See [[user-profile]] and [[project-learning-agents]].

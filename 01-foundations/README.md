# Lesson 1: Foundations — What Is an Agent?

## What You'll Learn
- The definition of an AI agent and how it differs from chatbots and pipelines
- The Observe → Think → Act loop
- Why actions are represented as data (dicts), not direct function calls
- The importance of safety limits (max_steps)

- Python 3.10+
- No API keys needed for this lesson
